What This Is

Stream Deck profiles are JSON files stored at %APPDATA%\Elgato\StreamDeck\ProfilesV2\. Writing the right JSON to that directory is all it takes to configure every button automatically. The generator also creates 288×288 PNG icons per category using Pillow.

Icon generation (Pillow)

from PIL import Image, ImageDraw, ImageFont

def make_icon(label, emoji, bg_hex, accent_hex) -> Image:
    img  = Image.new("RGB", (288, 288), bg_hex)
    draw = ImageDraw.Draw(img)
    draw.rounded_rectangle([8,8,280,280], radius=24, outline=accent_hex, width=3)

    # emoji top-centre, label bottom-centre
    em_font  = ImageFont.truetype("seguiemj.ttf", 100)
    txt_font = ImageFont.truetype("arialbd.ttf", 28)
    draw.text((144, 90),  emoji,       font=em_font,  anchor="mm", embedded_color=True)
    draw.text((144, 220), label[:12],  font=txt_font, anchor="mm", fill=accent_hex)
    return img

Fallback: skip icons entirely — Stream Deck shows the PythonScriptDeck default + button title text. Works fine, icons are cosmetic.
